# NEPSE Analyzer

NEPSE Analyzer is a one-month, project-based learning application for tracking daily Nepal Stock Exchange prices, identifying daily gainers and losers, and comparing recently published quarterly financial reports.

## First-month goal

- Display a NEPSE market summary
- Search and filter listed companies
- Rank the top five daily gainers and losers
- Display company price history
- Track recently published quarterly reports
- Compare revenue, net profit, and EPS quarter over quarter and year over year
- Show data sources and update timestamps
- Build a responsive light/dark interface

## Initial technology path

1. HTML, CSS, and JavaScript with sample JSON data
2. ASP.NET Core REST API using C#
3. MySQL relational database
4. A validated daily data-ingestion process
5. Python, statistics, and analytical features later

## Important boundary

The first version provides market information and measurable comparisons. It does not provide buy/sell recommendations, execute trades, or claim to predict future prices.
